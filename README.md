# Avito-merch-shop
Тестовое задание для стажёра Backend-направления (весенняя волна 2025)

## Описание
### Сервис для работы с ПВЗ
На ПВЗ несколько раз в день привозят новые товары, которые были заказаны через Авито. Прежде чем их отдавать заказчику, необходимо сначала проверить и внести информацию в базу. Из-за того, что ПВЗ много, а товаров ещё больше, нужно реализовать механизм, позволяющий в разрезе каждого ПВЗ увидеть, сколько раз в день к ним приезжали товары на приёмку и какие товары были получены.

## Взаимодействие с БД
Так как по условию задания, было запрещено использовать ORM для взаимодействия с базой данных, то в проекте была реализована работа с SQL запросами (находятся в директории app/db/queries/), где для каждой сущности (auth, pvz, reception, product) созданы отдельные модули с функциями, возвращающими SQL запросы и параметры. Используются параметризованные запросы с заполнителями (%s) и отдельным списком параметров. Библиотека psycopg2 автоматически экранирует параметры, чтобы не допустить SQL-инъекций. Pydantic модели проверяют входные данные до выполнения SQL запросов. Помимо этого, используются контекстные менеджеры для гарантированного завершения транзакций, а также реализован автоматический rollback при ошибках.

## Инструкция по запуску
1. Клонируем репозиторий и переходим в целевую папку:

```
git clone https://github.com/valkievan/Avito-pvz.git
cd Avito-pvz
```

2. Собираем и запускаем контейнер:

```
docker compose up --build
```
Миграции применяются автоматически во время запуска контейнера

*После запуска API будет доступен по адресу: http://localhost:8080*
